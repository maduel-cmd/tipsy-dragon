```
public/assets/
├── items/
│   ├── prepared/   # מנות מוגמרות 512×512 (המבורגר, סטייק, בוקר…)
│   └── sides/      # תוספות ובר (צ׳יפס, הוט־דוג, כנפיים, בירה…)
```
