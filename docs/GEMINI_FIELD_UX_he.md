# מיפוי Gemini → בר הפוד־טרק

מקור: [שיתוף Gemini](https://share.gemini.google/y6nuxhDnG2FS)  
**החלה על:** `apps/foodtruck-bar` בלבד — לא על TrailLink (`apps/web`).  
הכותרת בשיחה דיברה על מפות/TrailLink; כאן מיושמים רק הרעיונות הרלוונטיים למשחק בר.

| רעיון בשיחה | יישום בפוד־טרק | סטטוס |
| --- | --- | --- |
| עקרון האגודל (≥64dp, חצי תחתון) | כפתורי מדף גדולים + **אזור אגודל קבוע** (מגש / הגישו) בתחתית | ✅ |
| משחק מהשנייה הראשונה | כפתור **«שחקו עכשיו»** בלי חובת מסך סביבה | ✅ |
| Micro-tutorials (~30ש׳) | טיפים קצרים בתוך המשחק (לא מדריך ארוך) | ✅ |
| מצב שמש / ניגודיות | מתג «מצב שמש» | ✅ |
| אופליין ברור | Service Worker + שבב מקוון/אופליין | ✅ |
| זוהר POI | לקוח דחוף / נבחר | ✅ |
| פידבק מיידי (juice) | צלילים קצרים + התפרצות ויזואלית בהגשה | ✅ |
| תפקידי Co-Op | «תחנת עבודה» (מסנן מדף) + אופציונלי במסך סביבה | ✅ חלקי |
| PTT / WebRTC / מפות אמיתיות | לא רלוונטי למשחק בר סטטי | ❌ במכוון |

מסמכי עזר: `GEMINI_SOURCE_FULL_he.md`, `PRODUCT_REQUIREMENTS_FROM_GEMINI.md`.
